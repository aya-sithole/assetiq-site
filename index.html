Manual test script
T1 Clean sign-in. Open the prototype fresh. Tap a demo chip, then Log in. Expect the dashboard with no extra step.
T2 No external dependency. Repeat T1 with no other account signed in anywhere.
T3 Core functions. As Staff: open an asset, edit condition and notes, log an issue. As Org Manager: also edit the serial number and open Organisation and Tickets.
T4 Role enforcement. As Viewer: the Edit button is hidden. Ask the AI Assistant about portfolio value: it refuses. Check the audit log as Org Manager for the refusal.
T5 Signed-out access. Log out, then reload. Protected screens are unreachable until you sign in.
T6 Failed sign-in. Enter a wrong password three times. Expect a 30-second lockout, then a normal sign-in works.
T7 Sign-out and expiry. Log out, or set the 30-second timeout and wait. Expect a return to the login screen.
T8 Audit log. As Org Manager, open Audit Log after T1 to T7 and screenshot the entries.
Reset demo
Restores the seed assets and tickets to a known state. The audit log is append-only by design (see supabase.sql) and is not cleared by this. Org Manager only.
